# My Portfolio

A modern, responsive personal portfolio website built with React and Vite. Showcasing projects, experience, and skills with a sleek, animated design.

## Features

- ⚡ **Fast & Modern** - Built with React 19 and Vite for optimal performance
- 🎨 **Responsive Design** - Beautiful, mobile-friendly layout with Tailwind CSS
- ✉️ **Contact Form** - Integrated email functionality via EmailJS
- 🎭 **Smooth Animations** - Engaging animated components and transitions
- 🚀 **Fast Refresh** - Hot module replacement for seamless development
- 📦 **Optimized Build** - Production-ready build configuration

## Tech Stack

- **React 19** - UI library
- **Vite** - Build tool and dev server (using Rolldown)
- **Tailwind CSS** - Utility-first CSS framework
- **EmailJS** - Email sending for contact form
- **Lucide React** - Icon library
- **ESLint** - Code quality and consistency

## Project Structure

```
src/
├── components/        # Reusable UI components
├── layout/           # Layout components (Navbar, Footer)
├── sections/         # Page sections (Hero, About, Experience, Projects, Contact)
├── assets/           # Images and static assets
├── App.jsx           # Main app component
├── main.jsx          # Entry point
└── index.css         # Global styles
```

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
```bash
npm install
```

### Development

Run the development server:
```bash
npm run dev
```

The site will be available at `http://localhost:5173`

### Build

Create an optimized production build:
```bash
npm run build
```

### Preview

Preview the production build locally:
```bash
npm run preview
```

### Lint

Check code quality:
```bash
npm run lint
```
